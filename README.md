# Opeyemi Michael Lawal · Systems, drawn

Portfolio as an engineering drawing set. One static page, no build step: open `index.html` or host the folder anywhere.

- `index.html` holds all content, styles and script. Sheet copy is plain HTML; the diagrams, traces and faults live in the `SYS` object in the script.
- `assets/plates/` are screenshots of the live products (captured 24 Oct 2026). `assets/og.jpg` is the link-preview image.
